| 項目 | 統一様式 |

| 事例 | `【事例】生徒Ｋ` ＋ `思判表 A` `主態度 A` `相関`、Ｂ事例は「生徒Ｋと同じ基準で見とると…」 |
| 末尾 | `Ｃ評価` の扱い、`【整理できたこと・今後へ向けて】`（□見出し） |

## 着色（見取りの色分け）

統一様式が生徒の記述を①黄・②赤・③青で色分けしている手法を踏襲し、本資料では④緑を加えた４色で運用する。

| 色 | 意味 | 主に関わる観点 |
|---|---|---|
| ①黄 | 制度・政策の目的と仕組みを、資料から読み取った事実に基づいて記述している | 知識・技能 |
| ②赤（桃） | 政治面だけでなく、経済・生活・信仰などの側面にも記述している（多面的） | 思考・判断・表現 |
| ③青 | 幕府の立場だけでなく、大名・百姓・キリスト教徒などの視点からも記述している（多角的） | 思考・判断・表現 |
| ④緑 | 判断の基準を示し、反証や範囲の限定を踏まえて自分なりの答えを出している。またその答えを見直して方法を調整している（価値判断・意思決定／自己調整） | 思考・判断・表現／主体的に学習に取り組む態度 |

色の分量ではなく色どうしのつながり（相関）で質を見る。生徒Ｍ（Ｂ）は黄・赤・青が揃っていても緑が現れないためＡにならない、という差が説明できる形にしてある。

表の塗りも観点ごとに揃えた（知＝`FFF2CC`／思＝`FCE4EC`／態＝`DEEAF6`）。

## 内容の対応

- 添付指導案（全11時間）の第１～５時を対象とし、前期の評価場面を具体化した。
- 提示された Google フォーム３件の設問構成を評価物として位置付けた（【フォームとの対応】）。
- 生徒の回答は未取得のため、生徒Ｋ・生徒Ｍはいずれも判定を共有するための**想定例**。Ａ・Ｂの判定例は本単元用に具体化したものであり、国が定めた一律の判定基準ではない。
