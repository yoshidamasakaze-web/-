## 産業革命の授業スライド（.pptx）

単元「欧米の近代化と産業革命（産業革命は、人類を幸せにしたのか）」全10時間のうち、
**第7時【本時】「産業革命は私たち人類に何をもたらしたのか」** を1コマ通しで進行できる投影用スライド。

年間指導計画の書きぶりに合わせ、単元名は対立軸を含む問いの形、評価規準は「功罪について
多面的・多角的に考察している」の文言に揃えてある。

### 構成（全31枚）

| 範囲 | 内容 |
|---|---|
| 1-4 | 教師用。単元の位置づけ／トンネル方式の設計図／50分の流れと活動形態 |
| 5-9 | 導入（トンネルの入口）。着ている服 → 綿糸1/12・綿花85倍 → 本時の問い |
| 10-15 | 展開1。資料カード12枚を「光／迷い／影」に分類（グループ4人・12分） |
| 16-18 | 展開2。子どもの発言を歴史的事実に重ねて学習課題を立ち上げる |
| 19-22 | 展開3。解決策の共通点 →「資本主義」→ 主発問と立場表明 |
| 23-25 | 討論のゆさぶり資料3種（貧困率／格差・気候変動・児童労働／「やめられる？」） |
| 26-28 | まとめ。功罪の両面 →「やめるか」ではなく「どう作り直すか」／振り返りと次時 |
| 29-31 | 教師用付録。板書計画／評価規準と見取り／うまくいかないときの手立て |

### 設計上のポイント

- **トンネル方式**：入口は「今日着ているシャツ1枚」の一点だけ。掘り切ってから広い問いへ抜け、
  終盤（25・27枚目）で再び服に戻して入口と出口をつなぐ。
- **課題の立ち上げ**：16枚目で子どもに解決策を出させ、17枚目の対応表で歴史的事実
  （工場法・労働組合・チャーティスト運動・公衆衛生法・社会主義）に重ねる。教師が先に
  答えを言わない順序を守れば、課題が自然に立ち上がる。
- **活動形態**：「個 → グループ → 全体」を2回まわす。展開1はグループ（迷いを必ず生む）、
  展開2は全体（教師が板書に拾う）。

### 各スライドの発表者ノート

全31枚に、時間配分・発問の言い方・予想される生徒の反応・机間指導で見取る点・留意点を記載。
発表者ツールを開いて授業を進行する前提。

### 数値の扱い

グラフ・数値はすべて概数で、出典をスライド下部に明記している（マディソン・プロジェクト、
チャドウィック報告1842年、世界銀行／Our World in Data、IPCC、ILO・ユニセフ ほか）。
**授業前に使用中の教科書・資料集の数値と照合すること。**

特に14枚目の「平均死亡年齢17歳」は平均寿命ではない（乳幼児死亡率の高さを強く反映した数字）。
スライド内に注記を入れてあるが、口頭でも必ず触れる。

### 想定時数

1コマ50分で通す設計。2時間扱いにする場合の切れ目は18枚目（課題の設定）。
情報量が多いため、学級の実態によっては2時間扱いを推奨。

