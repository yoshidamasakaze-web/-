# 画像フォルダ

授業用スライド（絵入り）で使う当時の絵を、ここに入れます。

```
画像/01.jpg
画像/02.jpg
　　…
画像/12.jpg
```

`.png` でも読み込みます。どの番号が何の絵かは、リポジトリ直下の
`画像リスト.md`（または `画像さがし.html` をブラウザで開く）を見てください。

入れたあと、リポジトリの直下で次を実行するとスライドにはめ込まれます。

```
npm install pptxgenjs
node tools/産業革命_授業用スライド_生成.js
```

画像が足りない番号は、点線の枠のまま残ります。1枚ずつ足していって構いません。

**すべて著作権の保護期間が満了したパブリックドメインの作品を選んでください。**
ウィキメディア・コモンズでライセンス欄が `Public domain` または `PD-old` に
なっているものが該当します。
